# Multi-System DOCK6.13 De Novo Data Generation

This repository contains a workflow for large-scale **DOCK6.13 De Novo molecular generation** across multiple receptor systems and anchor fragments.

The workflow systematically generates molecules for receptor-anchor combinations using a common De Novo protocol. Receptor-specific and anchor-specific parameters are assigned automatically, allowing the same molecular generation procedure to be applied across the complete input set.

The resulting molecules are collected into a multi-MOL2 dataset for downstream molecular similarity, clustering, and chemical-space analyses.

## Scientific Workflow

Each independent De Novo calculation corresponds to a single:

```text
receptor system + anchor fragment
```

For each calculation, the workflow automatically assigns the appropriate:

```text
dn_fraglib_anchor_file
receptor_site_file
descriptor_grid_score_grid_prefix
```

The remaining DOCK6.13 De Novo parameters are maintained consistently across calculations.

This produces a systematic set of independently generated molecular populations in which the receptor environment and starting anchor are varied while the underlying De Novo generation protocol remains fixed.

## Workflow Scripts

### `000.config.sh`

Defines the input locations and computational settings used throughout the workflow.

This includes the locations of:

- receptor systems
- anchor fragments
- DOCK6.13
- De Novo fragment libraries
- DOCK6.13 parameter files
- generated calculation data

The workflow scripts obtain their common configuration from this file.

### `001.discover_inputs.sh`

Discovers the receptor systems and anchor fragments available for the calculation.

The discovered inputs are recorded in:

```text
state/systems.txt
state/anchors.txt
```

The script also verifies that the molecular, receptor, library, parameter, and executable files required for the De Novo calculations are available.

### `002.setup_DN_runs.sh`

Generates a DOCK6.13 De Novo input file for every receptor-anchor combination.

Each calculation receives an independent:

```text
DN.in
```

The appropriate anchor fragment, receptor spheres, and receptor grid prefix are inserted automatically while maintaining the common De Novo protocol.

### `003.make_task_list.sh`

Constructs the complete calculation table:

```text
state/tasks.tsv
```

Each entry identifies one receptor-anchor De Novo calculation and its corresponding calculation directory.

### `004.run_one_task.sh`

Executes one calculation from the task table.

Usage:

```bash
bash 004.run_one_task.sh TASK_ID
```

For example:

```bash
bash 004.run_one_task.sh 1
```

Each calculation is executed as an independent serial DOCK6.13 process.

Existing valid molecular outputs are recognized so that completed calculations are not unnecessarily repeated.

### `005.run_DN_systems.slurm`

Executes the receptor-specific production calculations through SLURM.

Each array task corresponds to one receptor system, with independent anchor calculations distributed across the allocated computational resources.

This script is invoked by the submission script.

### `006.submit_DN.sh`

Submits the complete set of receptor-anchor calculations.

Usage:

```bash
bash 006.submit_DN.sh
```

The number of receptor systems is determined from the discovered system list.

### `007.check_DN_results.sh`

Evaluates the completion status of all calculations.

Usage:

```bash
bash 007.check_DN_results.sh
```

Each calculation is classified as:

```text
SUCCESS
FAILED
MISSING
```

The results are recorded in:

```text
state/status.tsv
```

The script also determines the number of molecules generated by the completed calculations.

### `008.concatenate_results.sh`

Collects the valid molecular outputs from the completed De Novo calculations.

Usage:

```bash
bash 008.concatenate_results.sh
```

The molecules are concatenated into:

```text
combined/All_DN_Generated.mol2
```

A corresponding provenance table is generated as:

```text
combined/All_DN_Generated_manifest.tsv
```

The manifest records the receptor system, anchor fragment, number of molecules, molecule index range, and source calculation associated with each contribution to the combined dataset.

## Running the Workflow

Configure the required paths and calculation settings in:

```text
000.config.sh
```

Discover and validate the receptor systems and anchor fragments:

```bash
bash 001.discover_inputs.sh
```

Generate the receptor-anchor De Novo input files:

```bash
bash 002.setup_DN_runs.sh
```

Construct the calculation task table:

```bash
bash 003.make_task_list.sh
```

A single calculation can be executed first to validate the generated input:

```bash
bash 004.run_one_task.sh 1
```

Submit the complete calculation set:

```bash
bash 006.submit_DN.sh
```

After the calculations have completed, evaluate the results:

```bash
bash 007.check_DN_results.sh
```

Incomplete calculations can be resubmitted using:

```bash
bash 006.submit_DN.sh
```

Calculations with existing valid molecular outputs are skipped automatically.

After the required calculations have completed, construct the final molecular dataset:

```bash
bash 008.concatenate_results.sh
```

## Complete Execution Sequence

```bash
bash 001.discover_inputs.sh
bash 002.setup_DN_runs.sh
bash 003.make_task_list.sh
bash 004.run_one_task.sh 1
bash 006.submit_DN.sh
bash 007.check_DN_results.sh
bash 008.concatenate_results.sh
```

## Calculation Outputs

Each individual De Novo calculation produces:

```text
DN.in
DN.out
DOCK_DN.denovo_build.mol2
```

The molecular output:

```text
DOCK_DN.denovo_build.mol2
```

contains the molecules generated for a specific receptor-anchor calculation.

The workflow records the complete calculation status in:

```text
state/status.tsv
```

## Combined Molecular Dataset

Successful molecular outputs are collected into:

```text
combined/All_DN_Generated.mol2
```

This multi-MOL2 file represents the combined molecular population generated across the receptor-anchor calculations.

The provenance of the combined molecules is maintained in:

```text
combined/All_DN_Generated_manifest.tsv
```

allowing sections of the final molecular dataset to be traced to their originating receptor and anchor calculations.

## Downstream Analysis

The combined molecular dataset can be used for subsequent analysis of generated chemical space, including:

- molecular similarity analysis
- molecular clustering
- molecular diversity analysis
- Similarity Island analysis
- receptor-dependent molecular-space comparison
- anchor-dependent molecular-space comparison

The workflow therefore provides a reproducible approach for generating structured De Novo molecular datasets across multiple receptor environments and starting anchor fragments.
